This is the source code of the Python requests library (v2.32.3). Trace the complete call chain of `requests.get(url)` from the entry point to opening the actual HTTP connection.

Requirements:
- List each function/method in call order, with its file path and line number.
- Explain what Session, PreparedRequest, and HTTPAdapter are each responsible for.
- Point out where the connection pool is created and where it is reused.
- Answer in English, in no more than 15 bullet points.

## Rubric
Ground truth (check line numbers against materials/requests):
1. api.py `get` → `request` → creates `sessions.Session()` in a `with` block.
2. `Session.request` → builds `Request`, calls `prepare_request` → `PreparedRequest.prepare` (models.py).
3. `Session.request` → `Session.send` → `get_adapter(url)` → `adapters.HTTPAdapter.send`.
4. `HTTPAdapter.send` → `get_connection_with_tls_context` (2.32.x) → urllib3 `PoolManager.connection_from_host/url` → `conn.urlopen`.
5. Pool created in `HTTPAdapter.init_poolmanager` (called from `__init__`); reused because the adapter/PoolManager is kept on the Session (`mount`), and urllib3 pools per host.
